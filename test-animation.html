🧪 Animation Test

动画测试页面

移动鼠标查看动画效果 / 向下滚动查看视差效果

动画效果检查清单

✨ 应该看到的效果：

  • ✅ 顶部区域有红色边框（用于调试）
  • ✅ 背景图片可见
  • ✅ 鼠标在顶部移动时，背景和文字会轻微偏移
  • ✅ 向下滚动时，背景图片会向下移动（视差效果）
  • ✅ 可以看到飘动的粒子（白色/金色小点）

🐛 如果看不到效果，请检查：

  1. 打开浏览器控制台（F12），查看是否有 JavaScript 错误
  2. 确认 main.js 已加载（Network 标签页）
  3. 硬刷新页面（Ctrl + Shift + R 或 Cmd + Shift + R）
  4. 检查是否开启了"减少动画"设置

🔍 调试信息

打开浏览器控制台，输入以下命令测试：

// 检查函数是否存在
document.querySelectorAll('.page-header-with-bg').length

// 检查粒子 canvas 是否创建
document.querySelectorAll('.page-header-particles').length

// 检查背景图片元素
document.querySelector('.page-header-bg-image')
⬇️ 继续向下滚动测试视差效果 ⬇️
