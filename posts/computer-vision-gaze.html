2026-06-04 Computer Vision Gaze

Gaze 信息在第一视角动作识别中的作用

第一视角视频天然包含"我正在看哪里"的线索。Gaze 信息可以补足普通 RGB 视频难以表达的注意、目标和意图。

为什么 gaze 重要

在第一视角动作识别中，相机视角通常跟随佩戴者运动。手、物体、背景会频繁遮挡或抖动，模型需要从复杂场景里判断真正相关的区域。Gaze 可以作为一种弱监督或辅助模态，提示模型关注人正在交互的目标。

可能提供的线索

  • 注意先验：眼动点附近区域往往包含当前任务相关物体。
  • 动作阶段：动作开始前的 gaze 转移可能暗示下一步目标。
  • 意图补充：相同手部动作在不同注视目标下可能代表不同语义。
  • 噪声过滤：在复杂背景下，gaze 可以帮助模型降低无关区域权重。

融合方式

一个直观做法是把 gaze 点转换为 heatmap，与 RGB 特征在空间维度融合。也可以在 transformer 结构中把 gaze 当作额外 token 或 attention bias，让模型在时序建模时利用注视变化。

# 简化示意：把 gaze heatmap 作为附加通道
rgb = load_video_clip()          # [T, 3, H, W]
gaze = build_gaze_heatmap()      # [T, 1, H, W]
model_input = concat(rgb, gaze)  # [T, 4, H, W]

实验时需要注意

Gaze 标注可能存在采样频率、同步误差和个体差异。实验中需要明确 gaze 是训练阶段可见、推理阶段可见，还是只作为蒸馏/监督信号使用。不同设定代表不同的应用边界。
