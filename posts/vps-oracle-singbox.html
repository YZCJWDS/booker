2026-06-05 VPS Linux

Oracle VPS 与个人代理/博客部署笔记

这篇文章整理个人 VPS 的基础部署思路：静态博客放在 Nginx 下直接访问，代理和实验服务保持隔离，日常运维尽量可重复。

目标

个人 VPS 不需要复杂后台。博客只承担展示和归档作用，因此最稳妥的方案是纯静态文件加 Nginx。这样迁移成本低，安全面也小。

目录约定

博客目录统一放在 /var/www/blog，Nginx 只负责静态文件访问。后续新增文章时，直接上传 HTML、CSS、JS 和资源文件即可。

sudo mkdir -p /var/www/blog
sudo rsync -av --delete ./ /var/www/blog/
sudo chown -R www-data:www-data /var/www/blog

Nginx 配置思路

当前没有域名时，可以用 server_name _; 接收公网 IP 访问。静态站点的核心是 root、index 和 try_files。

server {
    listen 80 default_server;
    server_name _;

    root /var/www/blog;
    index index.html;

    location / {
        try_files $uri $uri/ /404.html;
    }

    error_page 404 /404.html;
}

安全习惯

  • 不要在博客目录放配置文件、私钥、数据库备份或令牌。
  • SSH 使用密钥登录，关闭不必要端口，系统定期更新。
  • 代理服务和静态博客分开管理，避免把实验配置暴露到 Web 根目录。
  • 每次修改 Nginx 后先执行 nginx -t，确认配置无误再 reload。

后续计划

等有域名后再补充 HTTPS、访问日志分析和更细的缓存策略。当前阶段优先保证内容发布简单、路径清晰、回滚方便。
